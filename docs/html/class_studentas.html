Detailed Description

Išvestinė klasė iš Zmogus studento duomenims saugoti.

Saugo namų darbų pažymius, egzamino pažymį ir skaičiuoja galutinius balus pagal medianą arba vidurkį.

Note
Galutinio balo formulė:
galutinis = 0.4 * nd_rezultatas + 0.6 * egzaminas

Naudojimo pavyzdys:

// Sukurti iš srauto
std::stringstream ss("Jonas Jonaitis 8 7 9 6 10");
Studentas s(ss);
// Išvesti
std::cout << s;
// Gauti balą
double med = s.galBalas(mediana);
double vid = s.galBalas(vidurkis);
